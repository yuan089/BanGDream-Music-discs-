# 🎵 模組介紹

## 1. 基礎模組 - 音樂播放機

### 物品列表
- 隨身聽
- 特製 Jukebox
- 客製化卡帶合集
- 刻錄機

---

## 2. 特性
- 一切附加音樂將會由 **DLC 形式**發佈，基礎模組為靈活的音樂播放器
- **隨身聽**：可隨身攜帶並播放，附近玩家能聽見小範圍聲音
- **特製 Jukebox**：可播放任何碟片並重複播放，Parrot 可與之互動，播放時有特效
- **客製化卡帶合集**：可裝載 60 首音樂，可在刻錄機刻錄音樂 ID
- **刻錄機**：可刻錄歌曲，提供三種選項：
  1. 刻錄身上所有歌曲  
  2. 檢索或選擇刻錄歌曲  
  3. 一鍵清除所有歌曲  

---

## 3. 合成方式
- **隨身聽**：由 1 銅錠 + 1 鐵錠合成  
- **特製 Jukebox**：由遊戲自帶的 Jukebox 合成  
- **客製化卡帶合集**：由 1 紅石粉末 + 1 鐵錠合成  
- **刻錄機**：由 9 個銅錠合成
